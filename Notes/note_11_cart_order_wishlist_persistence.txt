5. HEART BUTTON ON HOME PAGE -> SAVES TO WISHLIST
------------------------------------------------------------
PROBLEM:
  The heart button on product cards was purely visual (local
  component state only, lost on refresh, not connected to anything).

WHAT WAS DONE:
  - Wired ProductCard heart button to read/write the same
    localStorage wishlist key as the dashboard
  - Heart state initialized from localStorage on mount:
      -> Filled red heart = product already in wishlist
      -> Hollow heart    = not saved yet
  - Clicking heart saves product to user_wishlist_[email]
  - Product immediately appears in dashboard Wishlist tab
  - Shows "Added to Wishlist" toast popup for 1.8 seconds
  - Toggling again removes it from localStorage and dashboard
  - Fires custom browser event "wishlist-updated" so the dashboard
    re-reads the wishlist live without needing a page reload

HOW THE SYNC WORKS:
  ProductCard clicks heart
    -> writes to localStorage
    -> fires window event "wishlist-updated"
       -> UserDashboardPage listener triggers loadWishlist()
          -> setWishlist(updated items)
             -> WishlistTab re-renders with new product

FILES CHANGED:
  - frontend/src/components/home/ProductCard.jsx

7. BUG FIX — BLANK PAGE (TEMPORAL DEAD ZONE CRASH)
------------------------------------------------------------
PROBLEM:
  After the wishlist changes, dashboard showed blank page.
  Browser console error:
    "Uncaught ReferenceError: Cannot access 'profileData'
     before initialization at UserDashboardPage.jsx:70"

ROOT CAUSE:
  A useEffect at line ~63 referenced profileData.email in its
  dependency array, but the profileData useState declaration
  was 14 lines BELOW it. JavaScript "const" cannot be accessed
  before its declaration (Temporal Dead Zone / TDZ rule).

  Wrong order:
    line 63: useEffect(..., [profileData.email])  <- uses it
    line 77: const [profileData] = useState(...)  <- declares it

FIX:
  Moved profileData and profileSaved state declarations to
  the TOP of the component, before all helpers and effects
  that reference them.

  Correct order:
    line 38: const [profileData] = useState(...)  <- declares first
    line 63: useEffect(..., [profileData.email])  <- uses after

FILES CHANGED:
  - frontend/src/pages/user/user_dashboard/UserDashboardPage.jsx
