====================================================================
      NOTE 07: DYNAMIC ABOUT US SECTION & ADMIN FRONTEND SETUP
====================================================================
Date: September 2, 2026
Project: MERN Ecommerce (BloomShop)

1. MONGOOSE BACKEND MODEL & REST API
--------------------------------------------------------------------
- Model created: `backend/models/About.js` storing default and custom configuration:
  * Section Badge ("About BloomShop"), Main Title, Description text
  * Subheading & Sub-description text
  * Image URL, Image Quote Badge, Image Quote Text
  * Checkpoint Bullets (Ethically Sourced Materials, Quality Checks)
  * Action Button Text ("Explore Products")
  * 4 Store Stats Counter Cards (Value & Label)
  * 4 Feature Pillars (Title, Description, Accent Colors)
- API Routes built in `backend/index.js`:
  * GET `/api/about`: Fetches section data from MongoDB (seeds defaults if empty).
  * POST `/api/about`: Saves/updates section details in MongoDB database.
  * POST `/api/upload-about-image`: Uploads picture files to Cloudinary (or fallback base64).

2. ADMIN DASHBOARD FRONTEND SETUP DROPDOWN & TAB
--------------------------------------------------------------------
- Integrated `About Us Setup` inside the Admin Navbar **Frontend Setup** dropdown menu directly below `Category Setup`.
- Created `AboutTab.jsx` component allowing admins to:
  * Edit all text, titles, subtitles, quotes, and stats.
  * Pick/upload custom section showcase pictures using the **Browse & Upload File** button or typing direct image URLs.
  * Preview live changes in real-time before saving.
  * Reset settings to default values anytime.

3. STOREFRONT HOMEPAGE INTEGRATION
--------------------------------------------------------------------
- Updated `AboutUs.jsx` component on the homepage:
  * Dynamically fetches live data from MongoDB `/api/about`.
  * Listens to custom event `about-section-updated` for instant cross-component re-rendering without page refresh.
  * Includes resilient fallback logic to ensure page always displays cleanly.
