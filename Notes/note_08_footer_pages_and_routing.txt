2. SHOP PAGE BLANK SCREEN BUG FIX
--------------------------------------------------------------------
- Problem: Clicking the Shop link rendered a blank page.
- Root Cause: Backend endpoint `/api/products` returns `{ products: [...] }`. Calling `.filter()` directly on the returned object caused a JavaScript runtime exception (`products.filter is not a function`).
- Solution:
  * Implemented safe array extraction checking `Array.isArray(res.data?.products)`.
  * Added fallback to `productsData` (`@/data/products.json`) ensuring the catalog renders cleanly even if offline or if database is empty.
  * Added defensive null-checking for search and category filters.
