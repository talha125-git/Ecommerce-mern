1. OBJECTIVES & REQUIREMENTS:
   - Provide an all-in-one Admin Settings page (`SettingsTab.jsx`) to manage:
     * Store Brand Title & Tagline (Dynamic in browser tab & document).
     * Store Favicon (Dynamic with direct Image Link URL & file upload).
     * Terms & Conditions (Editable text directly reflected on `/terms`).
     * Privacy Policy (Editable text directly reflected on `/privacy`).
     * Customer Support Helpline Phone Number.
     * Official WhatsApp Helpline Number (with direct testing link `wa.me/...`).
     * Support Email & Physical Store Address.
     * Social Media Profile Links (Instagram, Facebook, Twitter/X).
   - Ensure About Us remains exclusively handled by the dedicated About Us tab (`Frontend Setup -> About Us Setup`).
   - Remove dynamic image logo to keep standard clean brand text (`BLOOMSHOP`) across Header, Footer, and Admin Sidebar.
   - Make Favicon and Title fully dynamic across the entire application.

2. ARCHITECTURE & IMPLEMENTATION DETAILS:

   A. BACKEND (MongoDB Atlas & Express API):
      - Models (`backend/models/Settings.js`):
        * Extended `SettingsSchema` with `favicon`, `termsConditions`, and `privacyPolicy`.
        * Added persistence for `supportPhone`, `socialWhatsapp`, `supportEmail`, `storeAddress`, and social profiles.
      - REST API Endpoints (`backend/index.js`):
        * `GET /api/settings`: Returns store settings merged with fallback defaults.
        * `POST /api/settings`: Upserts settings document atomically in MongoDB.
        * `POST /api/upload-brand-asset`: Handles direct file uploads for brand assets to Cloudinary (`ecommerce/brand/favicons`) with resilient base64 fallback.

   B. GLOBAL REACT CONTEXT (`frontend/src/context/SettingsContext.jsx`):
      - `SettingsProvider` & `useSettings()` hook:
        * Provides global reactive access to `settings`, `updateSettings`, and `refreshSettings`.
        * Caches settings in `localStorage` under `bloom_store_settings` for zero-flicker loading.
      - Real-Time DOM Favicon Sync:
        * Listens to `settings.favicon` and dynamically modifies or injects `<link rel="icon">` in the document `<head>`.
      - Real-Time Document Title Sync:
        * Listens to `settings.storeName` and updates `document.title` across the web app.
      - App Root (`frontend/src/App.jsx`):
        * Wrapped `<BrowserRouter>` inside `<SettingsProvider>`.

   C. ALL-IN-ONE ADMIN SETTINGS PAGE (`frontend/src/pages/admin/SettingsTab.jsx`):
      - Section 1: Browser Favicon & Store Title (Dynamic):
        * Direct "Favicon Image Link (URL)" input field (supports external image URLs like `https://.../icon.png` or `/favicon.svg`).
        * "Open Link in New Tab" quick action button to preview image link in browser.
        * "Copy Link" button with instant clipboard feedback.
        * "Upload Favicon File" button (.ico, .png, .svg) with automatic processing.
        * "Reset Default" button to quickly restore `/favicon.svg`.
        * Simulated Live Browser Tab Preview showing real favicon icon + store name.
        * Dynamic Store Title and Tagline inputs with live page title preview card.
      - Section 2: Legal Policies (Terms & Conditions & Privacy Policy):
        * Full-width multiline textareas with live character counters.
        * Directly drives content on `/terms` and `/privacy`.
      - Section 3: Direct Contact & WhatsApp Helpline:
        * Contact phone, Support Email, and Physical Store Address.
        * Official WhatsApp number with live "Test Link" (`wa.me/...`) to verify WhatsApp messaging.
      - Section 4: Social Media Channels:
        * Instagram, Facebook, and Twitter/X URL inputs with branded SVG icons.
      - Top Sticky Save Bar + Bottom Floating Action Button with status notification toasts.

   D. FULL STOREFRONT DYNAMIC INTEGRATION:
      - Header (`Header.jsx`):
        * Dynamic document title and static clean brand text (`BLOOMSHOP`).
      - Footer (`Footer.jsx`):
        * Uses `useSettings()` for dynamic store address, support phone, email, WhatsApp quick-chat button, and social media profiles.
        * Links directly to dynamic `/terms`, `/privacy`, and `/about`.
      - Checkout & Order Placement (`CheckoutPage.jsx`):
        * Displays WhatsApp Order Assistance banner ("Need order help? Chat on WhatsApp ↗").
        * Order Confirmation Screen: Displays dynamic store contact info and an instant WhatsApp support button pre-filled with the placed Order ID (`ORD-XXXXXX`).
      - Legal Pages (`TermsPage.jsx` & `PrivacyPolicyPage.jsx`):
        * Dynamically renders paragraphs from `settings.termsConditions` and `settings.privacyPolicy`.
        * Displays store contact boxes with dynamic email and phone.
      - Contact Page (`ContactPage.jsx`):
        * Dynamic address, phone, WhatsApp chat card, and email.
      - About Us Page (`AboutPage.jsx`):
        * Kept decoupled and dedicated to your `/api/about` setup (`AboutTab.jsx`).
