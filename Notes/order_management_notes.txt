OVERVIEW:
This document summarizes the real-time, MongoDB-backed Order Management & Checkout
System implemented to replace hardcoded dummy orders with a dynamic order workflow.

--------------------------------------------------------------------------------
1. BACKEND ARCHITECTURE & DATA MODEL
--------------------------------------------------------------------------------
- File Location: backend/models/Order.js
- Mongoose Order Schema:
  * orderId: String (Unique code e.g. "ORD-849204")
  * customer: {
      fullName: String,
      email: String,
      phone: String,
      address: String,
      city: String,
      country: String (Default: "Pakistan")
    }
  * items: Array of [{ id, name, price, quantity, image }]
  * totalAmount: Number
  * paymentMethod: String ("card", "cod", "wallet")
  * status: String Enum ("Pending", "Processing", "Shipped", "Delivered", "Cancelled")
  * timestamps: createdAt, updatedAt

- RESTful API Endpoints (backend/index.js):
  * POST /api/orders: Creates and saves a new order directly into MongoDB Atlas.
  * GET /api/orders: Retrieves all store orders sorted by newest first.
  * PUT /api/orders/:id/status: Updates status (Pending -> Processing -> Shipped -> Delivered -> Cancelled).
  * DELETE /api/orders/:id: Deletes an order from MongoDB by ID.

--------------------------------------------------------------------------------
2. FRONTEND CHECKOUT SYSTEM
--------------------------------------------------------------------------------
- File Location: frontend/src/pages/user/CheckoutPage.jsx
- Logic & Features:
  * Calculates real-time subtotal, estimated tax (8%), and dynamic shipping ($0 if subtotal > $50).
  * Enforces user authentication before placing an order.
  * Submits complete order payload to backend via Axios (POST /api/orders).
  * Displays order confirmation screen with generated Order ID and clears global CartContext state.

--------------------------------------------------------------------------------
3. ADMIN DASHBOARD ORDER CONTROLS
--------------------------------------------------------------------------------
- File Location: frontend/src/pages/admin/OrdersTab.jsx
- Features & UI Controls:
  * Removed all hardcoded static dummy orders (Sarah Jenkins, Michael Chen, etc.).
  * Real-Time Table View: Displays Order Code, Date/Time, Customer Profile, Full Street Delivery Address, Item Thumbnails, Total Price, and Status Selector.
  * Expandable Detail Drawer: Click Chevron Down to reveal full delivery address card and itemized product breakdown.
  * Modal View: Click Eye icon for full popup view of customer contact details and order status controls.
  * Real-Time Status Selector: Color-coded dropdowns to update order states in MongoDB instantly.
  * Multi-Field Search: Filter orders by Order Code, Name, Email, Phone, Address, or City.
  * Status Pill Filter: Filter list by All, Pending, Processing, Shipped, Delivered, or Cancelled.
