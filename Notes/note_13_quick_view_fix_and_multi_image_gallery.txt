          NOTE 13: QUICK VIEW FIX, MULTI-IMAGE GALLERY & PRODUCT DETAILS
================================================================================

1. QUICK VIEW "PRODUCT NOT FOUND" BUG RESOLUTION:
   - Root Cause:
     * When starting frontend dev server before the backend was online, the catalog
       loaded from local fallback `products.json` using numeric IDs (e.g., id: 1).
     * Clicking "Quick View" navigated to `/product/1`.
     * Once the backend came online, `ProductDetailsPage` fetched MongoDB documents,
       which only possessed 24-char ObjectId `_id` strings and no `id` field.
     * The page searched for `_id === "1"` or `id === "1"`, found nothing, and
       displayed "Product Not Found".
   - Solution Implemented:
     * Added `id: { type: String }` to `ProductSchema` in `backend/models/Product.js`.
     * Implemented `GET /api/products/:id` in `backend/index.js` supporting lookup by:
       - MongoDB ObjectId (`_id`)
       - Custom string identifier (`id`)
       - Numeric seed mapping (e.g. "1" resolves to "AirFlex Runner")
     * Added intelligent `resolveProduct` in `ProductDetailsPage.jsx` that cross-references
       server products by ID, fallback data by name, and 1-based index positions.
     * Added automatic retry in `ProductList.jsx` to smoothly switch from fallback data
       to live MongoDB products once the backend server responds.

2. MULTI-IMAGE PRODUCT GALLERY & CLICKABLE THUMBNAILS (ProductDetailsPage.jsx):

   - Main Image Navigation:

   - Dynamic Multi-Angle Fallback:

       angles (side profile, sole detail, on-foot view) so buyers can always interact
